## Discrepancies

**Doc says:** Mentions only `detect_confusables()` function.

**Actual:** `confusables_count()` exists in unicode_tools.py:218 - a performance helper that directly counts confusables without building a list.

**Action:** Update arch doc to document the helper function.

### 2. Missing `unicode_scripts()` Batch Function (Medium Priority)

**Doc says:** Mentions only individual script detection.

**Actual:** `unicode_scripts()` exists in unicode_tools.py:123 - returns script list for all characters in a single call.

**Action:** Update arch doc to document the batch function.

### 3. Missing TypedDict Definitions (Low Priority)

**Doc says:** Describes data structure informally.

**Actual:** `ScriptInfo` (unicode_tools.py:21) and `ConfusableInfo` (unicode_tools.py:29) TypedDicts are defined but not documented.

**Action:** Update arch doc to include schema definitions.
