## Usage

### Basic Conversion

```bash
calc "100ft in meters"
# 30.48 m

calc "5km to miles"
# 3.107 mi
```

### Arithmetic with Units

```bash
calc "30m + 100ft"
# 60.48 m

calc "1GB - 512MB"
# 512 MB

calc "2h + 30min"
# 2.5 h
```

### Unit Division

```bash
calc "100km / 2h"
# 50 km/h

calc "60mi / h"
# 60 mi/h
```

### Temperature

```bash
calc "temp(100C, F)"
# 212 F

calc "temp(32F, C)"
# 0 C

calc "temp(0C, K)"
# 273.15 K
```

## Python API

```python
from nl_clicalc import evaluate_raw, UnitValue, get_conversion_factor

# Evaluate with units
result = evaluate_raw("30m + 100ft")
print(result)  # 60.48 m

# Get conversion factor
factor = get_conversion_factor("ft", "m")
print(factor)  # 0.3048

# Check if unit
from nl_clicalc import is_unit
print(is_unit("m"))   # True
print(is_unit("xyz")) # False

# List all units
from nl_clicalc import get_all_units
units = get_all_units()
```
